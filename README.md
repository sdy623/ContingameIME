# 按键切换

- 单击快捷键，在**临时输入状态**和**关闭状态**之间切换
- 双击快捷键，切换到**开启模式**。
- 当鼠标移动并有事情发生时，**临时输入状态**切换到**关闭状态**。

## 依赖

- NeoForge
